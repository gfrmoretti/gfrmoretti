## Featured Case Study

### 🏦 Automated Credit Card Proposal Engine — Itaú (2024)

> **Problem:** Thousands of customers already had pre-approved credit limits sitting in internal systems, but no automated process existed to generate and deliver card proposals to them.

> **Solution:** Designed and built an end-to-end automated proposal-generation system, integrating multiple microservices and AWS Lambda functions to identify eligible customers, generate proposals, and trigger the full card onboarding flow — without manual intervention.

> **Result:** **10,000 new card proposals generated in the first week** of launch. Customers who previously had no path to their credit were automatically reached with a ready-to-approve proposal.

*Stack: Kotlin · Spring Boot · AWS Lambda · SQS · PostgreSQL · Terraform · GitHub Actions*

## Open Source

### [anmap](https://github.com/gfrmoretti/anmap) — Annotation-based Java Mapper

![Status](https://img.shields.io/badge/status-stable-brightgreen)
![Stars](https://img.shields.io/github/stars/gfrmoretti/anmap?style=flat)
![Language](https://img.shields.io/badge/language-Java-ED8B00?style=flat)

An annotation-driven object mapper for Java, designed for **Clean Architecture** projects where explicit mapping layers are required between domain, application, and infrastructure models.

Built to solve a real mapping problem in production microservices at CI&T — shipped and used across multiple services. Prioritizes **zero configuration** and simplicity for lightweight mapping scenarios.

> *For more advanced use cases and complex type conversions, [MapStruct](https://mapstruct.org/) is the recommended choice.*
